# SpeechAnnot
Расширение для хрома позволяющее преобразовывать речь в текст и сохранять его в буфер обмена

Бэкграунд скрипт запускает скрипт микрофона. Скрипт микрофона слушает речь и переводит её в текст с помощью Web Speech API. 
Полученный текст передаётся бэкграунд скрипту. А он уже передает текст контент скрипту. Контент скрипт сохраняет текст в буфер обмена.
